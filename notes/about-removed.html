How HuggingFound is built

The whole thing is a small Node server and a hand-written page, with no framework and a single third-party library (Anthropic's SDK, for the optional Claude check). Everything else, from the Hugging Face client to the GPU rental to the Google sign-in, is written in this repository so that it can be read end to end.

  • Search ranks models by name, by category and by what people say about them in model cards, Hub discussions, Civitai, GitHub issues, Hacker News, Lemmy, YouTube and Reddit, with refusal-prone models filtered out.
  • Fit and speed are estimated from the file size and the machine's memory and GPU before anything is downloaded; measured times replace the guesses after a real run.
  • Local runs drive Ollama, whisper.cpp and stable-diffusion.cpp from a fixed set of checked commands, including merging a diffusers repository into one checkpoint.
  • GPU rental starts a RunPod machine from a custom image built in GitHub Actions, stops it when idle or at a daily spend cap, survives server restarts, and moves the rental to another data centre when one runs out of stock.
  • Privacy by construction: the browser talks to the rented GPU directly, so what a visitor says to a model never passes through the site. Account keys are encrypted at rest. The privacy page is kept true by the tests.
  • Claude as a second opinion: every answer and every picture can be checked or revised by Claude with the visitor's own key, which is never stored.
  • Hosting: one Docker image on Render, defined in the repository, with Google OAuth sign-in and guest sessions that expire on their own.
  • Testing: unit and API suites against stand-ins for the Hub, RunPod, Ollama and the GPU agent, and a Playwright test that drives the real page in Chrome through a rental.
